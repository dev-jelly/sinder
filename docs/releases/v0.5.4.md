# Sinder 0.5.4 — 파일 경로 바로 찾기와 탐색 단축키

찾고 싶은 파일의 경로를 붙여 넣고, 키보드나 마우스 버튼으로 폴더 기록을 오가세요. 이번 프리뷰에는 [@nus-dev](https://github.com/nus-dev)의 [PR #1](https://github.com/dev-jelly/sinder/pull/1), [PR #2](https://github.com/dev-jelly/sinder/pull/2)를 통합했습니다.

> 배포 준비 중입니다. Apple Developer 계약 갱신 후 공증과 최종 패키지 검증을 완료하면 macOS Apple Silicon용 앱을 공개합니다.

## 파일 경로로 바로 찾기

**⌘L**로 경로 입력창을 열고 파일의 전체 경로를 입력하면, 그 파일 한 개를 표시하고 선택합니다. 로컬 파일과 SSH 서버의 파일 모두 사용할 수 있습니다.

![파일 경로를 입력해 해당 파일만 표시한 Sinder](https://raw.githubusercontent.com/dev-jelly/sinder/v0.5.4/docs/screenshots/file-path-pr/single-file.png)

*임시 테스트 데이터로 촬영한 화면입니다.*

- 확장자가 없는 파일과 숨김 파일도 실제 파일 유형을 확인해 표시합니다.
- 새로 고침하거나 다른 탭에 다녀와도 해당 파일 화면을 유지합니다.
- **전체 폴더 보기**를 누르면 상위 폴더의 일반 목록으로 돌아갑니다.
- 대상 파일이 삭제되면 새로 고침 시 전체 폴더로 돌아갑니다. 파일 심볼릭 링크를 폴더로 잘못 여는 동작도 방지합니다.

## 뒤로·앞으로 이동

| 입력 | 동작 |
| --- | --- |
| macOS **⌘← / ⌘→** | 활성 패널의 기록에서 뒤로 / 앞으로 |
| **Ctrl+← / Ctrl+→** | 활성 패널의 기록에서 뒤로 / 앞으로 |
| 마우스 뒤로 / 앞으로 버튼 | 활성 패널의 기록 탐색 |

경로 입력창 등에서 텍스트를 편집할 때는 방향키 단축키를 가로채지 않습니다. 분할 보기에서도 활성 패널만 이동합니다. 기존 **⌘[ / ⌘]**, **Alt+← / Alt+→**도 유지합니다.

## 리뷰 과정에서 보완한 점

- 마우스 버튼을 길게 누를 때 운영체제 명령과 마우스 이벤트가 함께 들어와 두 번 이동하는 문제를 재현하고 수정했습니다. 버튼을 놓을 때까지 한 번의 입력으로 처리합니다.
- 별도로 누른 키보드 단축키가 마우스 중복 입력으로 오인되지 않도록 했습니다.
- 공개용 스크린샷 생성 도구를 최신 앱 API에 맞췄습니다.

## 설치와 업데이트

배포 파일이 공개되면 ZIP을 풀어 **Sinder.app**을 **응용 프로그램** 폴더에 넣으세요. 업데이트 전 파일 전송과 원격 편집 저장을 마치고 Sinder를 **⌘Q**로 종료한 뒤 교체합니다. 교체 후에는 Finder의 **응용 프로그램 → Sinder**를 여세요. 이전 다운로드 사본을 가리키는 Dock 아이콘은 새 설치본으로 다시 등록하세요.

## 검증 범위

단위·실제 SSH 통합 테스트 **53개**, Electron 데스크톱 시나리오 **15개**가 통과했습니다. 긴 마우스 클릭의 중복 이동은 수정 전 실패·수정 후 통과를 확인했습니다. 타입 검사·빌드와 공개용 스크린샷 3장 생성도 통과했습니다. 최종 배포 앱의 서명·공증 검증 결과는 배포 시 반영합니다.

마우스 버튼은 Chromium 입력과 Electron 운영체제 명령으로 검증합니다. MX Master 등 실물 마우스, Windows/Explorer 및 Intel Mac은 실기 검증하지 않았습니다. 0.5.3의 Finder 중첩 드래그와 사용자 서버의 대용량 전송 검증 범위도 유지합니다.
